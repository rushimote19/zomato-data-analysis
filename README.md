# Zomato Restaurant Data Analysis

## Project Overview
This project analyzes Zomato restaurant data to identify business insights related to restaurant ratings, cuisines, locations, and pricing.

## Objectives
- Analyze restaurant ratings and customer preferences.
- Explore popular cuisines and restaurant locations.
- Identify trends that can support business decisions.
- Build interactive dashboards and visual reports.

## Tools & Technologies
- Microsoft Excel
- MySQL
- Power BI
- Tableau

## Project Workflow
1. Data collection and exploration
2. Data cleaning and preparation
3. SQL-based data analysis
4. Dashboard development
5. Insights and business recommendations

## Key Learnings
- Data cleaning and transformation
- SQL querying and analysis
- Data visualization
- Business insight generation
